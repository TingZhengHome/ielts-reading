## 🌟 Overview
Designed specifically for high-achieving IELTS candidates aiming for Band 8.5+, this platform provides full native academic narration for all 10 flagship reading passages across natural sciences, humanities, and contemporary governance.

## 🎧 Features
- **Native Academic Accents**: Narration by distinguished native academic voices (British RP, Australian, and North American) calibrated to standard academic pacing (-2% speed).
- **Paragraph-by-Paragraph Academic Typography**: Elegant serif presentation with paragraph tags (A-F) designed to minimize cognitive load.
- **Bilingual Parallel Text**: Full Traditional Chinese scholarly translation for rapid reading comprehension validation.
- **Academic Vocabulary Matrix**: Core academic words, phonetic notation, part of speech, and high-frequency collocations.
- **Complex Sentence Deconstruction & Writing Formulas**: Flagship grammatical breakdown and transferable writing formulas with Task 2 high-scoring applications.
- **Mobile-Responsive Audio Player**: Interactive scrub bar, 10s skip controls, variable playback speed (0.75x to 1.5x), and loop functionality.
- **QR Code Deep Linking**: Hash-based routing (`#unit01` to `#unit10`) enables seamless transition from printed physical handbooks to mobile audio.
